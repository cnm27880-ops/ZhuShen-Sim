# 標籤數值翻譯對照（2026-11）

哈基米寫的標籤效果（`src/data/codexTags.js`）是給回合制戰鬥設計的（命中、爆擊、壓力、背包…），這個遊戲是「每個房間算一次通過率」，所以只能把它翻成引擎有的 7 種數值。**哈基米的文字一個字都沒動，只有 `src/data/tags.js` 的數值欄位被翻譯。**

## 引擎可以用的數值

| 欄位 | 意思 |
|---|---|
| 戰力 `powerPct` | 個人戰力 % |
| 通過率 `passBonus` | 全隊單房通過率（每位成員各算一次，全隊合計上限 ±10%） |
| 類型／環境 `genreBonus`／`envBonus` | 特定類型副本／特定環境的通過率（併入同一個 ±10% 上限） |
| 積分 `rewardPct` | 通關積分 % |
| 少受傷 `injuryShield` | 受傷時少一級的機率（負數 = 多受一級） |
| 閃避 `dodge` | 被點名受傷時直接閃過的機率 |
| 浮動 `swing` | 每個房間通過率隨機浮動 ± |

## 翻譯規則

1. 攻擊力／傷害／爆擊／命中 → 戰力或全隊通過率；防禦／生命／承傷 → 少受傷；閃避 → 閃避（負的閃避沒有對應，改成「多受傷」）；掉落／寶箱／商店／結算 → 積分；恐怖／懸疑類 → 靈異類；忽強忽弱 → 浮動。
2. 條件式、機率式效果（「生命低於 30% 時…」「40% 機率…」）依觸發頻率折算成較小的數字。
3. 引擎完全沒有的機制（商店 8 折、系統漏洞直接通關、吃遺體回血…）沒有對應欄位，維持原值並在下表註明。
4. **校正係數**：一開始完全照規則翻，整體標籤強度比原本弱（主要是原本的類型加成被拿掉），尾王首通中位數從 Day 27／68／162／301／379 拖到 36／102／196／423／417，第 5 章首通比例 55% → 13%。所以統一把正面效果 ×1.2、負面 ×0.8、類型加成再 ×1.2。天生神力（物攻 +15%）、身輕如燕的閃避（+12%）、健身房推銷員的力量（+10%）這種可以一對一對應的數字不套係數。
